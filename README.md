# Wyckoff Trading System

威科夫交易系统，包含多种高胜率策略和回测功能。

## 策略分析报告

详细的策略分析报告请参阅：
- [三大高胜率策略分析报告](strategy_analysis_report.md)

## 主要功能

1. **威科夫九大检验点分析**
2. **VSA量价分析**
3. **多因子信号融合**
4. **模拟盘选股系统**
5. **策略性能跟踪**

## 策略概览

系统包含以下三大高胜率策略：

### 1. 威科夫7项通过 + 确认事件
- 胜率：80%
- 平均收益：2.41%

### 2. 威科夫事件 + 高价值VSA标签
- 胜率：76.9%
- 平均收益：2.22%

### 3. 多因子强化做强多头策略
- 置信度：95%
- 适用于高置信度买入信号
