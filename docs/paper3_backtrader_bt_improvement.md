# 模拟盘三策略改进回测对比报告

- 股票池: 24 只蓝筹 · 初始资金 100 万 · 单边成本 0.4% · 同持≤3 · 持有≤20 根
- 基准: 止损3% / 固定止盈15% / 无弱市过滤 / 价值无降权
- 改进: 止损5% / 止盈15%激活+移动止盈回落8% / 弱市(上证 sh000001 收盘<MA20 → 1仓+停价值) / 价值资金×0.6·同时≤1只
- 折中: 止损4% / 移动止盈回落6% / 其余同改进

## 3. 改进逻辑与效果归因

1. **止损放宽 3%→5%**: 假突破被 3% 小止损反复割肉的损耗显著下降;
2. **移动止盈 (15% 激活, 高位回落 8% 离场)**: 让赢家持有更久, 盈利上限打开, 均持由 13.8 根升至 15~17 根;
3. **弱市过滤 (指数<MA20 → 1仓 + 停用价值)**: 熊市最大回撤 -26.4%→-14.3%, 是熊市转正 (纪律 17笔·58%, 左侧 19笔·63%) 与回撤压缩的主要来源;
4. **价值吸筹降权 (资金×0.6, 同时≤1只)**: 降低弱策略的敞口, 全周期价值仓位从 9 笔增至 59 笔总量仍最低, 弱市被停用.

## 4. 已知权衡与建议配置

- 唯一代价集中在**牛市**: 弱市过滤在牛市启动段 (指数尚未收复 MA20, 924 行情前两周) 会压制仓位上限并禁用价值, 移动止盈在单边趋势中会回吐部分收益 → 牛市收益 +31.1% → +8.2% (折中 +10.7%), 但夏普 1.49→0.75 仍在健康区间.
- **推荐生产配置**: `--stop 0.04 --trail 0.06` (折中): 全周期 +93.1% / 夏普 1.07 / 回撤 -13.8%, 更均衡.
- 若想保留牛市弹性: 牛市时段可 `--weak-off` 临时关闭弱市过滤, 熊市重新开启.
- 遗留短板: 价值吸筹折中配置下全周期胜率仅 22% (n=9), 建议后续提高 `--va-min-conf` 或并入纪律信号清洗, 或彻底停用该策略.
