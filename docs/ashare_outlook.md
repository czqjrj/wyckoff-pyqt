# A股市场状态系统 (`ashare_outlook`)

一个**不预测单日涨跌**的 A 股市场分析系统：描述当前状态、给出历史相似状态下的收益分布、列出关键位与风险预算。

> 待办清单: [ashare_outlook_todo.md](ashare_outlook_todo.md)

## 文件

- `wyckoff/ashare_outlook.py` — 核心逻辑
  - 指数状态分 v2（趋势 60% + 回撤 40%；动量/低波动经消融剔除）
  - 状态标签 v3（按历史分位：≤10% 风险规避 / 10–25% 谨慎 / 25–50% 防御 / 50–75% 中性偏多 / >75% 进攻）
  - 历史类比（相似状态 → 未来 5/20/60 日收益分布）
  - 状态分历史分档回测（含 MA200 基线）
  - 关键位（P&F 区间/三档目标/均线/枢轴/近期高低点）
  - 情景触发条件
  - 行业轮动与防御/成长风格差
  - 风险预算
- `wyckoff/ashare_backtest.py` — 状态分机械规则 walk-forward 回测
- `wyckoff/ashare_journal.py` — 预测记录 / 回填 / 命中率统计
- `wyckoff/ashare_liquidity.py` — M1/社融/利率流动性确认
- `wyckoff/ashare_valuation.py` — 指数估值（PE/股息率/ERP，本地累积分位）
- `wyckoff/ashare_export.py` — 报告 PDF 导出（PyQt6，核心引擎不依赖）
- `wyckoff/ashare_watchlist.py` — 独立自选股列表（批量分析/批量记录）
- `ui/ashare_outlook_window.py` — 独立 PyQt6 窗口
- `scripts/ashare_outlook.py` — 命令行入口
- `scripts/ashare_outlook_gui.py` — GUI 启动器
- `tests/test_ashare_*.py` — 相关单元测试（不触网）

## 独立 GUI

```bash
python scripts/ashare_outlook_gui.py
```

- 选择主指数，勾选行业/ETF/流动性/估值/回测/对比
- 报告页顶部结论卡片：状态分徽章 + 一句话结论 + 仓位参考 + 关键位 + 预警，一眼可见；可一键复制结论
- 快捷键：F5 刷新、Ctrl+Shift+C 复制结论
- 七个页签：报告、图表（K线 + 状态分 + 回测净值 + 历史类比分布）、板块（含行业热力图）、个股、自选/批量、个股日志、预测日志
- 顶部预警标签：触发机械预警时红/黄提示，悬停可看明细；报告里也有“预警”小节
- 自选/批量：添加/移除自选股；批量分析（快速模式）和批量记录，结果写入个股日志
- 板块：90 个行业，按 20 日资金 + 当日强度排序，红涨绿跌；顶部行业热力图；支持搜索、点表头排序、单击行业看成分股、双击成分股直接分析
- 成分股：东财成分股优先；东财限流时用新浪行业兜底（部分行业是宽口径），界面会标注来源
- 个股：输入代码（如 `600519` / `sh600519`），调用旧 Wyckoff 系统做快速分析；勾选“抓资金/板块”可做完整确认（慢）
- 自动行业：分析个股时自动识别所属行业并填入下拉框；若用户已手动选择板块，则不覆盖
- 三击表：大盘 / 板块 / 个股 / 三击结论；板块可自动识别，也可在下拉框手动改，选完会重算“共振/逆风”
- “记录个股”：把代码/日期/阶段/综合分/方向/止损/目标写入 `wx_ashare_stock_journal.json`
- “个股日志”页：回填个股信号（5/20/60 日收益、回撤、目标/止损命中）并查看统计
- 图表页：K线（MA20/50/200 + P&F 上下沿）、状态分、机械规则净值、历史类比收益分布（5/20/60 日直方图）；可拖动分隔条调整高度
- 按钮：刷新、记录今日、回填、统计、导出（Markdown / PDF / 图表 PNG）
- 首次加载要拉行情/行业/ETF/宏观数据，可能需要十几秒

## 用法

```bash
# 默认：上证指数，输出 Markdown 报告
python scripts/ashare_outlook.py

# 输出 JSON
python scripts/ashare_outlook.py --json

# 指定主分析指数
python scripts/ashare_outlook.py --primary sh000300

# 写入文件
python scripts/ashare_outlook.py --out reports/ashare_outlook.md

# 导出 PDF（按后缀自动识别）
python scripts/ashare_outlook.py --out reports/ashare_outlook.pdf

# 跳过行业抓取（更快/离线）
python scripts/ashare_outlook.py --no-sectors

# 跳过国家队/ETF 确认（更快）
python scripts/ashare_outlook.py --no-etf

# 跳过流动性/信用确认（更快）
python scripts/ashare_outlook.py --no-liquidity

# 跳过估值确认（更快）
python scripts/ashare_outlook.py --no-valuation

# 只跑状态分机械规则回测
python scripts/ashare_outlook.py --backtest

# 指定回测单边成本（bp）
python scripts/ashare_outlook.py --backtest --cost-bps 10
```

## 记录 / 回填 / 统计

```bash
# 每天收盘后记录一次（同一天重复记录会覆盖，不新增）
python scripts/ashare_outlook.py --record

# 过 5/20/60 个交易日后回填结果
python scripts/ashare_outlook.py --backfill

# 查看命中率、Brier、概率校准、按状态/ETF/流动性分组表现
python scripts/ashare_outlook.py --stats

# 个股信号：回填 / 统计
python scripts/ashare_outlook.py --stock-backfill
python scripts/ashare_outlook.py --stock-stats
```

日志默认写到用户数据目录的 `wx_ashare_journal.json`；也可以用 `--journal 路径` 指定。

统计口径：

- **方向命中**：5/20/60 日历史类比上涨概率 ≥55% 记“偏多”、≤45% 记“偏空”，中间记“中性”不计分。
- **Brier**：概率预测的误差，越低越好；要和“基线 Brier”比较，不能只看绝对值。
- **概率校准**：预测 60% 上涨的样本，实际上涨率是否接近 60%。
- **情景命中**：回填期内是否摸到区间上沿/下沿，判断走的是基准、向上突破还是向下破位。

注意：样本少、相邻交易日高度重叠，统计结果只能慢慢积累，不要用一二十条记录下结论。

覆盖指数：上证指数、沪深300、创业板指、中证500、科创50。

## 报告包含

1. **大白话结论**：用“问题 → 回答”表说清楚现在怎么样、钱在哪、关键位、怎么做；第一行是“一句话结论”，最后附“判断错了怎么办”和“术语速查”。
2. **指数状态表**：各指数状态分、历史分位、阶段、20日涨跌、距250日高；状态标签按历史分位（v3），5 档都能出现。
3. **和上次相比**：状态分、状态、阶段、收盘、ETF 确认的变化（有历史记录时才显示）。
4. **历史类比**：与当前状态最像的 60 个历史日，之后 5/20/60 日的上涨概率、中位数、10%/90% 分位；另给 **Wilson 95% 区间 + 非重叠有效样本**（独立样本少时区间很宽，别把单点概率当方向）。
5. **状态转移**：当前状态 → 未来 5/20/60 日落在各状态的经验概率，以及状态平均持续期；标注样本内不可达的分档。
6. **状态分历史分档**：不同状态档未来 20 日收益分布，与 MA200 基线对照。
7. **状态分机械规则回测**：状态分 → 仓位、MA200+状态分 overlay，与 MA200、买入持有对照（含成本）；另给 252 日滚动窗口的胜率、**最近 252 日样本外单独一段**（避免全样本结论掩盖近期失效）、**成分消融表**（各成分 IC / 分位价差 / 回测，解释 v2 配方的取舍），以及 **walk-forward 稳定性**（滚动 IC + 逐年超额）。
8. **关键位**：均线、P&F 区间、近端目标、三档目标及概率、支撑/阻力。
9. **国家队/宽基 ETF 确认**：ETF 日频主力流、三因子份额、季报持仓，聚合成“托底/平衡/撤退”，并和当前大盘状态对照；东财资金流断连时，用量价代理并明确标注“非真实申赎”。
10. **流动性/政策确认**：M1-M2、社融同比（主源累计同比，备源增量滚动同比）、SHIBOR 3M、10 年国债，合成“宽松/中性/偏紧”。
11. **情景**：基准/破位/反转三种条件，只写触发条件和路径，不写主观概率。
12. **行业与风格**：20 日资金 + 当日强度的相对强弱，防御/成长资金差。
13. **风险预算**：机械仓位参考区间（0–80%）。
14. **预警**：P&F 破位/跌破 MA200、状态或阶段切换、ETF 资金转向、广度/涨跌停极端。
15. **估值（中期锚，非择时）**：主要指数 PE(滚动)、历史分位、股息率、ERP（=100/PE − 10Y 国债）；分位来自本地每日累积，不足 250 日前标注“样本累积中”；PB 源当前不可用；创业板指不在中证官网估值文件内。
16. **数据源状态**：各数据源当前状态、最后成功时间、上次拉取耗时、失败/拉取次数、最近错误和失败退避剩余秒数。

## 方法要点

- **不使用未来数据**：状态特征只使用当日及以前数据；历史类比的候选日只取未来收益已知的日期。
- **不预测单日涨跌**：输出的是状态、经验分布和条件情景。
- **状态标签是“相对分位”不是绝对分档**：v3 用分数在自身历史中的分位（≤10% 风险规避 … >75% 进攻），5 档都能出现；早期 v1/v2 的绝对分档（≥70 进攻…）仍保留在 `state_abs` 字段里。分位用“截至当日”的历史计算，无前视；指数级分位会随历史推移而移动。
- **样本会重叠**：相邻交易日的未来收益高度相关，显示的样本数不是独立样本数。报告会额外给出“有效样本”（按非重叠窗口挑）和 Wilson 95% 区间；独立样本少时，区间很宽，单点概率不能当方向依据。
- **walk-forward 稳定性**：回测新增滚动 252 日窗口的 IC 检验 + 逐年超额。全样本 IC 为正但窗口内常为负，说明趋势型打分在 A 股震荡市容易被均值回归打脸——这是“状态分只当仪表盘、不单独择时”的直接证据。
- **P&F 概率不是指数专用**：它来自个股/合成样本的历史校准，只能作为参考。
- **国家队/ETF 是资金流代理**：不是官方持仓；份额变化可能受拆分/分红影响，异常大的 5 日变化不要当真实申购。
- **ETF 量价代理**：东财资金流断连时，用“实体额×成交量”估算 1/5/20 日资金方向；它只代表量价压力，不是真实申赎，报告会单独标注。
- **行业多源兜底**：同花顺/东财行业都失败时，改用新浪行业；新浪只有当日涨跌、没有 20 日资金，报告会标注“无20日资金”。
- **成分股兜底**：东财行业成分股常被限流；限流冷却期（10 分钟）自动改走新浪行业/板块详情，并在 GUI 标注来源。新浪兜底对部分行业是宽口径，不是同花顺原板块的精确成分。
- **自动行业识别**：优先用已加载的成分股本地映射；其次用巨潮/中证/申万公开行业分类；最后才尝试东财。识别结果只是“所属行业候选”，不改变 Wyckoff 个股分析本身。
- **机械预警不是交易信号**：预警只提示“状态切换/破位/资金转向/广度极端”等事件；阈值是人为规则，不预测单日涨跌。
- **批量分析是快速模式**：默认不抓资金/板块/基本面，只用于快速比较阶段/综合分/止损目标；正式结论仍建议单只完整分析。
- **自选股独立存储**：A股 GUI 自选股保存在 `wx_ashare_watchlist.json`，不读写旧 Wyckoff 的自选文件。
- **磁盘缓存兜底**：sectors/ETF/liquidity 的成功结果会写入 `wx_ashare_cache.json`；TTL 内新进程直接复用，TTL 后拉取失败则回退上一份成功数据并标记“过期”。
- **失败退避（限流保护）**：某数据源拉取失败或返回空时，进入短期冷却（板块/ETF 180s、流动性 600s、成分股 300s），冷却期内不再重复打源，直接回退旧值并标注“退避 Xs”；避免东财等接口被连续刷新打爆。
- **渐进加载**：GUI 先构建指数核心（指数、关键位、历史类比、回测）并立即渲染，再在后台补板块/ETF/流动性，完成后自动刷新报告；核心先可见，慢源不阻塞首屏。
- **流动性/信用是月频数据**：M1、社融有 1–2 个月滞后；利率低不等于马上涨，只说明资金环境偏松。
- **社融备源口径**：主源 `macro_china_new_financial_credit` 的“累计同比”失败时，改用 `macro_china_shrzgm`（社融增量，亿元）的 12 个月滚动同比。两者水平不可直接比较（备源通常更滞后、更平滑），报告会标注“增量滚动同比(备源)”并附注口径提示。
- **估值分位是本地累积的**：中证官网只提供最近约 20 个交易日，PB 与长历史源当前不可用；系统每天把 PE/股息率并入 `wx_ashare_valuation.json`，累计满 250 个交易日才给分位，之前只显示当前值和“样本累积中”。ERP 需要流动性层的 10Y 国债。估值只作中期锚，不是短期择时信号。
- **利率备源**：SHIBOR 3M 主源失败时用东财拆借利率，10Y 国债主源失败时用中债国债收益率曲线；两者仍是同一指标，不改变口径。
- **状态分 v2 消融（2026-11）**：对 4 个指数（上证/沪深300/创业板/中证500）2021-11~2026-11 做成分消融（未来 20 日收益 IC）：趋势是唯一全指数 IC 为正的组件；动量（上证 t≈-4.7）、低波动（沪深300 t≈-5.5，单独回测 -23.9%）出现显著负 IC，予以剔除；回撤保留 40% 权重（深度回撤后 A 股反弹特征）。v2 配方在 4 个指数的全样本与最近 252 日回测均不劣于旧配方，换手更低。消融只删"有证据的有害成分"，不是调参美化。
- **机械规则回测只是验证**：状态分 → 仓位是人为映射，不是最优参数；v2 全样本约打平（上证 +0.85%），仍跑不赢 MA200（+6.90%），说明它更适合当仪表盘/风险预算，不适合单独择时。
- **Overlay 也不是万能的**：MA200 打底、状态分只降风险；当前样本里 overlay 仍跑输纯 MA200，滚动窗口胜率也不高，所以只能当风险预算参考。
- **样本外偏弱是常态披露**：最近 252 日（2025-10 起）所有趋势型打分 IC 转负、回测普遍亏损，报告会把样本外单列，弱市里不要上调对状态分的置信度。
- **缺少估值/盈利预期**：系统目前没有 PE/PB 分位和盈利修正，不能单独作为交易依据。
