Wyckoff 威科夫分析客户端 · 使用手册

本工具基于威科夫 (Wyckoff) 方法体系, 对 A 股个股做量价分析, 输出阶段判断、VSA 信号、 P&F 点数图、资金透视、批量扫描、回测与 AI 解读。手册窗口顶部提供关键词搜索, 可随时 Ctrl+F 定位章节。

本工具输出仅为技术分析参考, 不构成投资建议。A 股为单边做多市场, 所有 偏空信号只给出减仓/离场/回避类建议, 严禁做空。

1. 启动与界面布局

启动后窗口分三块: 顶部主工具栏与状态栏、左侧自选股列表、中间五个标签页 (K线图 / P&F 点数图 / 技术指标 / 资金透视 / 解读)、右侧结论面板。底部状态栏显示当前股票 与建议, 分析进度与提示也会在此显示。

  • 主工具栏: 周期 (日线/120-15分钟) · 区间 (近1月~近5年) · 开始分析 · 刷新 · 加入自选 · 设置 · 左栏/右栏开关;
    右侧状态区: 当前股票名称、代码、现价、 涨跌幅与最新建议。
  • 左栏 / 右栏 可用工具栏小按钮或 Ctrl+Shift+W / Ctrl+Shift+R 一键显隐;
  • 若在"设置 → 基本"中配置了"默认载入"股票, 启动后自动分析该股票;
  • 资金透视 页图表较高, 窗口高度不足时该页提供竖向滚动条, 可最大化窗口查看 (本手册窗口同样支持最大化)。

2. 如何分析一只股票

2.1 输入方式 (支持三种)

  • 代码: 600104、sh600104、000001;
  • 股票名: 上汽集团;
  • 拼音: shangqi、sqjt (支持缩写)。

输入后按 Enter 或点击"开始分析"。也可在图表空白处直接敲字母弹出键盘精灵 (见 §5.2)。

2.2 周期与时间段

  • 周期: 日线 (默认) / 120分钟 / 60分钟 / 30分钟 / 15分钟;
  • 时间段: 近1月 ~ 近5年, 决定分析用的 K 线根数。
分析分钟级时工具会自动拉取日线作长周期参照, 识别"日线下跌 / 分钟反弹"类背离。

2.3 刷新与缓存

  • 刷新: 重拉最新行情并重新分析 (K 线 5 分钟内存缓存);
  • 强制刷新分析 (Ctrl+F5): 绕过本地缓存强制重拉;
  • 历史 K 线持久缓存在 wyckoff_cache.db, 跨会话复用节约流量; "工具 → 清除行情缓存"可一键释放磁盘。
缓存不足所选时间段时会自动失效重拉, 不会"时间段没起作用"。

3. 五种图表页

3.1 K线图

  • 滚轮: 缩放; 左键拖拽: 平移; 双击: 复位;
  • +/-: 缩放; ←/→: 平移; Home: 复位; Backspace: 向前翻页; F/End: 向后翻页;
  • 点击图上 VSA 信号标签: 弹出该信号的详细解释 (含义/方向/关注点/建议/失效条件);
  • 右键: 保存图片 / 复位视图;
  • 十字光标跟随鼠标显示实时价格与成交量。

3.2 P&F 点数图

点数图 (Point & Figure) 用 × / ○ 刻画价格运动, 忽略时间, 用于识别箱体、突破与目标位。 目标位测算遵循威科夫横向/纵向计数口径 (依据 Wyckoff Analytics Count Guide、 StockCharts ChartSchool、Incredible Charts P&F Guide 与 Wyckoff SMI 5-Step Method)。

  • 格值与反转: box 两种来源 (设置可选), 反转固定 3 格:
    • 百分比 (默认): box = 最新价 × 1.5% (取整到分);
    • 动态ATR: box = ATR(14) × 0.5 (系数可调), 随波动率自适应过滤噪声。
  • 横向计数 (Law of Cause and Effect): cause = count line 列数 × 格值 × 反转, 计数须把有/无 posting 的横向分格全部计入 (含空列); effect 投影为三档目标 — count line (最大) / TR 区间极值 (保守) / 两者中点 (中档)。
  • 纵向计数: 主升/主跌列高度 × 格值, 从该列底部 (向上) 或顶部 (向下) 投影;
  • 近端参考目标 为本工具自创的可到达口径 (区间边界外推 0.2×因, 相对现价 ±4% 封顶), 供历史命中核对; 非威科夫概念;
  • 准确率: 图注与"历史测算"行核对每段突破后是否到达目标 (±1 格容差), 检验威科夫 计数在历史段上的实际表现。
威科夫目标仅为 "stop, look and listen" 参考位置, 不承诺价格必到; 本工具以近端目标做可到达性校准, 满宽目标仅为教科书理想位。

3.3 技术指标

叠加常见指标 (成交量、均线、MACD/RSI 等), 纵向滚动查看单指标卡片。

3.4 资金透视

资金与股价配合度的一站式视图, 自上而下排列 (高度不足时竖向滚动):

  • 主力资金流向 (全宽): 大小单净流入与阶段结合的走势;
  • 资金分项 / 当前筹码堆积形态: 大单/超大单拆解与筹码分布;
  • 股东户数变化 / 供需强度: 筹码集中度与量价供需平衡。

3.5 解读 (AI 解读)

展示 AI 对本次分析报告的通俗解读 (需在设置中启用 AI 并配置 Key)。

4. 右侧结论面板

4.1 信号汇总

顶部卡片展示阶段、结构、趋势、资金、回测等核心结论。阶段颜色: 底/升=红, 区=琥珀, 顶/跌=绿。下方 VSA 标签条显示最近信号 (带 ✓ 高置信 / ! 谨慎标记)。

4.2 分析结论

左侧竖列表切换段落, 右侧显示当前段落 HTML 结论。标题栏提供 ▶ 语音朗读 与 A− / A+ 字号调整。导出报告 (Ctrl+E) 保存 txt + 各图 PNG 到数据目录。

历史胜率 段落: 每种事件除全量回测统计外, 还列出"其中 ✓ 已确认"子集的胜率与均收益 —— 已获后续 K 线跟进确认的事件命中率更高, 是"等确认再进场"的经验证据。

4.3 文字缩放

所有文字分析窗口 (分析结论、AI 解读) 标题栏都有 A− / A+ 按钮, 字号 7~18pt, 设置自动保存重启保留。

5. 自选股与键盘精灵

5.1 自选股列表

  • 工具条"加入自选"或 Ctrl+D 添加当前股票;
  • 双击 自选股加载分析; 右键: 加载分析 / 上移 / 下移 / 删除;
  • 卡片显示实时行情与阶段高亮色; "工具 → 刷新自选股行情"批量更新。

5.2 键盘精灵 (代码搜索)

在非输入框区域 (图表、列表、空白处) 直接敲字母或数字弹出搜索精灵, 输入 代码/名称/拼音, 回车或双击结果即加载分析。再次敲击字母继续在当前搜索框内追加, Esc 关闭。输入框内打字不触发。

这是最快的"键盘流"用法: 看图时直接敲 sqjt 回车即切换到上汽集团。

6. 选股体系

6.1 三类扫描 (选股菜单)

  • 扫描自选股: 批量分析自选股; 全市场扫描: 扫 A 股全市场;
  • 板块扫描: 按行业板块扫描成份股;
  • 扫描结果窗口支持 全选 / 加入自选股 / 存为待观察 / 导出 CSV, 双击行 加载分析。

6.2 综合选股 (Ctrl+Shift+S)

独立标签页, 多条件组合筛股 (阶段/信号/技术面), 结果同样支持加入自选与双击加载。

6.3 待观察候选池

扫描中"存为待观察"的股票汇总, 集中管理潜在标的, 可批量巡检。 "候选池巡检"专项扫描会标注每个候选已走强 / 已破位 / 继续观察。

6.4 扫描中心 (20 类专项扫描, Ctrl+Shift+M)

按功能聚合的专项扫描库, 双击条目即运行, 支持多选并行。本地三态 (量价) 扫描在全市场 检索; 行情增强类扫描需联网 (部分依赖 akshare, 失败自动跳过不阻塞)。

7. 指数行情

"指数"菜单内置常用指数一键加载: 上证指数 / 深证成指 / 创业板指 / 科创50 / 沪深300 / 上证50 / 中证500 / 中证1000 / 中证A500, 或"全部指数..."弹出对话框搜索选择。 指数与个股共用同一套分析流程。

8. 工具 (工具菜单)

  • 我的持仓 (盈亏跟踪): 记录买入价/数量/成本, 实时算盈亏与止损距离, 接近止损高亮, 可导出 CSV; 也是"持仓风险"扫描的数据源;
  • 自选股预警: 为自选股设置价格阈值 (突破/跌破) 或信号类型预警, 触发弹窗 + 语音;
  • 多股票对比: 并排显示自选股的阶段/信号/方向评分, 双击加载分析;
  • 校准中心 (Ctrl+Shift+A): 分层校准 — 模型校准 (L4 在线 LR)、 阶段带反馈标注 (人工纠正反哺准确率)、分析校准、信号校准 (L1 贝叶斯收缩 + Rank IC + 显著性验证)、信号时间线 (按股票→日期看每个信号的命中日历), 支持导出 JSON / CSV / 复盘周报, 可清空记录;
  • 个股备注 (分析菜单): 为当前股票记录买卖理由/观察要点; 清除行情缓存 管理本地数据。

9. 资金监测 (资金菜单)

  • 国家队持仓透视: 识别当前股票十大股东中的汇金/证金/社保, 附 AI 解读;
  • ETF 三因子份额监测: 用交易所份额变化推断汇金宽基 ETF 信号 (概率性, 非官方数据);
  • 国家队ETF跟踪: 跟踪国家队相关宽基 ETF。

11. 设置面板详解 (设置 → 设置... / Ctrl+,)

11.1 界面主题

  • 浅色 / 深色 (护眼): "设置 → 基本 → 界面主题"选择, 保存立即生效; 也可 视图 → 切换深色护眼主题 一键切换;
  • 深色主题为低亮度蓝紫基调, 适合夜间长时间盯盘; 四个图表页的背景、坐标轴、网格与 十字光标读数框随主题同步切换, 无需重新分析。

11.2 基本

  • 默认载入: 启动时自动分析的股票, 留空不自动;
  • 默认周期 / 时间段: 启动默认组合; 定时刷新行情: 每隔 N 秒自动刷新;
  • 基本面/资金流确认机制: 关闭即离线快速模式 (跳过外部抓取, 更快);
  • 界面尺寸: 自选股栏宽 / 右侧结论栏宽。

11.3 图表

  • 界面/图表字号; 绘制维斯波波段 (横盘/推进); 绘制买卖点锁 (触发/失效标记)。

11.4 回测与风控

  • 回测参数: 持有根数 / 最少样本 / 单边成本;
  • 分析灵敏度: 枢轴灵敏度 fast (细枢轴信号多) / normal (默认) / safe (粗枢轴 假信号少); 点数图格值 百分比或动态ATR (见 §3.2);
  • 仓位风险管理: 总资金 / 单笔风险 / 最小盈亏比 → 生成仓位建议。

11.5 AI

  • 启用 AI 反向证伪: 对看多/看空结论做反向审查;
  • 启用 AI 报告解读: 生成通俗解读; API Key / Base / 模型: 支持 DeepSeek 等 OpenAI 兼容接口, 默认 https://api.deepseek.com / deepseek-chat。
AI 为可选层: 未配置 Key 时自动跳过, 不影响离线分析功能。

11.6 语音播报

  • 启用解读语音播报 / 分析完成后自动播报; 引擎 auto / edge-tts / pyttsx3, 可调音色 与语速; 最大播报字数控制长度。

12. 常见问题与技巧

12.1 分析慢 / 卡

  • 关闭"基本面/资金流确认机制"进入离线快速模式;
  • 不配置 AI Key 即跳过 AI 解读与证伪; 历史 K 线走缓存, 首次拉取后明显更快。

12.2 退出时等很久 / 崩溃

  • 分析中 (尤其 AI 解读) 直接关窗会等后台线程结束再退出; 建议等状态栏回到"就绪" 再关闭。

12.3 语音没有声音

  • 确认"设置 → 语音播报"已启用; auto 不可用时换 edge-tts 或 pyttsx3; 检查系统声卡。

12.4 拼音搜索不到

  • 用完整拼音或代码; 缩写需在索引中; 名称搜不到可试代码。

12.5 数据来源

  • 行情自动在 新浪 → 东方财富 → 腾讯 间切换; 个别数据源短暂不可用时自动换源重试。 行情增强类扫描 (大宗/调研/涨停池/两融等) 依赖 akshare, 需联网且数据源偶发限流, 失败会自动跳过不阻塞整批。

12.6 如何看准一个信号

  • 点击 K 线图上的信号标签, 查看含义、关注点、失效条件;
  • 看跟进确认标记: 结论"近期事件"每个事件带 ✓ (已确认) / ✗ (未确认) / … (待确认) —— 只在事件被后续 K 线朝信号方向跟进确认后进场 (✓ 事件回测命中率显著更高);
  • 看高周期方向: "多维度共振"标注每个维度顺/逆高周期 —— 与周/月线方向一致的 信号权重 ×1.2, 冲突 ×0.6 (冲突降仓);
  • 看波动率状态: 低波动蓄势后的放量突破更可信, 高波动追高风险大;
  • 结合 资金透视 (资金是否配合) 与 阶段判断 综合决策;
  • 在校准中心查看历史判断的回评记录, 校准自己的阈值;
  • 可让 AI 反向证伪 给出相反观点再决策。
