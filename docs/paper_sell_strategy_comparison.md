# 模拟盘卖出策略对比：纯价格型卖出 vs 事件型空头信号卖出

**生成时间**: 2026-09-04  
**回测引擎**: `scripts/paper_replay_bt.py`（模拟盘引擎真实K线历史回放）  
**测试区间**: 2023-01-01 ~ 2026-09-03（约3.5年）  
**测试标的**: 沪深主板 25 只（`sh605xxx` 主板，已剔除创业板/科创板/北交所）

---

## 1. 背景与目的

模拟盘买入策略为双策略选股（纪律[强多头事件 Spring/Shakeout/ST/LPS/SC，conf≥90] 优先，无纪律信号时回退价值吸筹[底部整固+近20根吸筹事件]）。

卖出策略有两种可选形态：

1. **纯价格型卖出**（实盘当前默认）：仅依赖价格触发 —— 止盈(+15%) / 止损(-6%) / 破位(跌破近10根低点) / 到期。
2. **事件型空头信号卖出**（回测新增，未接入实盘）：在前者基础上，持仓期间若标的发生 **UTAD/LPSY 空头事件** 即主动平仓（作为风控信号）。

本报告对比两种卖出策略在**同一批股票、同一买入策略、同一参数**下的准确性与盈利能力，判断「买入+卖出策略闭环」是否改善效果。

## 6. 分析结论

### 6.1 事件型空头信号卖出（模式B）的收益影响
- **✅ 累计收益 / CAGR 大幅提升**：累计 +168% → +293%，CAGR +32% → +47%。交易笔数从 55 增至 171（3 倍），靠**高频换手、多次小收益累积**堆出更高净值。
- **✅ 盈亏比略升**：2.01 → 2.12。
- **❌ 胜率下降**：56.4% → 48.5%。空头信号卖出 100 笔平均仅 +0.78%、胜率 46%，把大量**本可继续上涨**的仓位提前止盈，剪掉了后续 +15% 的止盈机会（止盈笔数从 31 → 37，提高有限）。
- **❌ 最大回撤显著恶化**：-2.44% → -7.68%。高频换手放大了路径波动。
- **⚠️ 价值吸筹策略被严重拖累**：空头信号模式下价值吸筹胜率从 70% 跌至 26%、收益合计从 +86.9% 跌至 +9.6% —— 空头信号对底部整固型仓位杀伤最大（过早打断吸筹后的主升）。

### 6.2 核心矛盾
- 空头信号 (UTAD/LPSY) 在 25 只样本的 3.5 年历史中**频繁触发**（100/171 笔平仓），且单笔均收仅 +0.78%，**多数是噪音**而非趋势终结信号。
- 它更像「落袋为安 + 转仓换手」机制：牺牲**胜率与回撤**，换取**更高的累计收益与资金周转**。
- 若目标是「**高胜率、低回撤、持有趋势到止盈**」（模拟盘稳健风格），**纯价格型卖出更优**；若目标是「**最大化账面累计收益**」（可接受高回撤与低胜率），事件型空头信号卖出更有吸引力。

### 6.3 建议（如未来需接入）
若要在实盘启用事件型空头卖出且兼顾准确率，需先**降噪**，例如：
- 提高空头信号置信度门槛（当前不限 conf，几乎全量放行）；
- 缩短检测窗口（当前 `window=10` 根）；
- 仅在**已浮盈**时触发（避免打断底部整固仓位过早离场）；
- 或对冲掉价值吸筹策略，仅对纪律(趋势型)仓位启用。

---

## 7. 实盘现状说明（重要）

**当前实盘模拟盘（`wyckoff/paper.py`）未启用事件型空头信号卖出。**

- 实盘 `step` 的平仓触发仅有：止盈 / 止损 / 破位 / 到期（纯价格型）。
- 建仓 `fill_buy` 未传 `event_type`，持仓 `pos["event_type"]` 为 `None`，因此 `close_position` 中的 `evaluate_sell_reason` 仅改写平仓原因文本，**不触发任何平仓**——`sell_strategy.py` 中定义的 UTAD/LPSY 空头卖出实为「死代码 / 标签」。
- 即：**实盘对应本报告的模式A（纯价格型）**。模式B（事件型空头信号卖出）仅为回测脚本 `paper_replay_bt.py` 的对比实验（`--no-bear-exit` 可开关），**未接入实盘**。
