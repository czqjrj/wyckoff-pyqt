## 结论

1. **同日同板块重叠真实存在**: 同板块同日多信号让 raw 信号笔数虚高 20.9%
   (sector 去重 1380→1092), 产业链口径再砍 4.7pt (1027)。
2. **但该口径下对组合收益影响小**: 3 槽静态填充下执行笔数 146→145, 胜率与槽位 CAGR
   几乎不动。原因是剔除的重叠信号本身就高度同涨同跌, 槽位调度期重叠时只取其一,
   单笔期望 (≈+8.6%) 与盈亏比被保留, 与不去重几乎等价。
3. **"相关回撤放大"担忧在本口径不显著**: 逐笔口径最差单笔三档完全一致 (−28.11%),
   槽位累计 CAGR 持平。真实盘面的盘中回撤放大需要用逐日 stateful 组合回测
   (paper3_backtrader) 才能完全刻画; 本对照说明信号层面的板块重叠冗余是 ~21%,
   组合收益不因此高估, 但要求风控容忍同板块同日集中 (最多 3 槽中多只同板块)。
4. 建议: 生产保持不去重 (未发现需要强制的重叠惩罚), 但把"同日同板块最多 1 槽"作为可配置风控项,
   与盘面回撤观测 (paper _verify) 联动, 若出现同板块集中连亏再启用 sector 去重
   (回测已示其不损失单笔期望)。

> 历史回测, 不构成投资建议。
