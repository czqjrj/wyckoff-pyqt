# 威科夫分析客户端 · 可盈利性回测报告

- **生成时间**: 2026-08-29
- **评估范围**: 强多头事件策略（Spring / Shakeout / ST / LPS / SC / SOW_INVALID）在 A 股的历史可盈利性
- **数据来源**: wx_signal_accuracy.json（8,326 条已评估信号）+ 23 只自选股实时行情（push2delay 兜底）因果式路径回测
- **评估口径**: 20 根日 K 持有（≈1 个月），单边成本 0.4%（含税费合计单笔 ~0.8%），方向化收益

---

## 一、研究方法：三条独立证据链

为消除单一回测链路的偏差，采用三种互不依赖的口径交叉验证：

| 链路 | 数据 | 方法 | 特点 |
|---|---|---|---|
| A. 信号库存量统计 | 8,326 条信号已评估记录 | 历史扫描产生的真实信号 + 真实未来结果 | 样本量大，无进场时序约束 |
| B. 逐股因果回测 | 23 只自选股 700 根日线 | 每个历史时点只用当时已见数据重算枢轴/事件（`backtest_events`） | 无前瞻偏差，独立检测 |
| C. 组合层回测 | 23 只自选股 | 多股票信号按日期对齐，同持上限 3、5% 结构位止损、1/3 仓等权 | 反映信号重叠、仓位约束、止损 |

强多头事件集：Spring（83.6% 收缩命中）/ Shakeout（75.2%）/ ST（70.2%）/ LPS（64.5%）/ SC（66.4%）/ SOW_INVALID（66.4%），均为方向命中显著优于随机的多头类型。

## 二、链路 A：信号库存量统计（976 条强多头已评估）

按置信度分层（修复后的 conf 严格单调，验证校准模型有效）：

| conf 档 | 样本 | 胜率 | 平均/笔(20根≈1月) | 盈亏比 |
|---|---|---|---|---|
| 全部强多头 | 971 | 68.3% | +5.63% | 1.73 |
| ≥80 | 502 | 76.9% | +7.21% | 1.75 |
| ≥90 | 317 | 82.6% | +8.61% | 1.91 |
| ≥95 | 190 | 83.2% | +9.13% | 2.03 |
| ≥90 + 止损-5% | — | — | +7.31% | 3.22 |

要点：
- **置信度分档严格单调**（+5.6→+9.1%），是校准模型有真实区分力的直接证据（此前 VSA conf 恒 0、弱类型高分反向均已修复）。
- **止损-5% 显著改善盈亏比**（1.73→3.22），单笔最大亏损从 -30.3% 收紧至 -5%，验证结构位止损的价值。
- 最大连亏 **15 笔**——纪律与资金垫是实盘前提。

## 三、链路 B：逐股因果式路径回测（23 只）

`backtest_events`：在每个采样时点 `t` 只用 `df.iloc[:t+1]` 重算枢轴与事件，对未来窗口收益评分，消除前瞻偏差。结果：

| 指标 | 值 |
|---|---|
| 强多头事件-股票组合样本 | 80 条（类型-股票组合，n≥20） |
| 平均每笔收益（费后） | **+5.95%**（中位 +5.48%） |
| 胜率 | 82.5% |
| 盈亏比 | **2.96** |
| 超额 vs 各自买入持有 | +4.79%/笔 |
| 跑赢各自基准 | 78.8% |
| 正期望股票 | **23/23（100%）** |

单股平均收益区间：+0.39% ~ +20.04%（sh600900 最低、sz301098 最高），**无一只负期望**。

对照（诚实负结论）：**全部事件类型**（含空头/弱类型 SOS/JOC/PSY/BC/AR 等）组合后仅 +3.19%、盈亏比 1.68——若照单全收，盈利会被稀释；必须按"强多头 + 高 conf"筛选。

## 四、链路 C：组合层回测（同持上限 3 + 止损）

模拟接近实盘的执行规则：信号按到达时间入场，最多同持 3 只，5% 结构位止损（盘中触及即出，回测用最低价近似），1/3 资金每笔，仓位用尽时跳过新信号。

| 指标 | 值 |
|---|---|
| 策略执行笔数 | **285 笔 / ~2.8 年（≈102 笔/年）** |
| 平均每笔（费后） | +2.91%（按 1/3 仓注入组合） |
| 胜率 | 53.0% |
| 盈亏比 | **1.99** |
| 最差单笔 | **-5.8%**（止损钳制，无深坑） |
| 资金曲线 | 1 万 → 12.9 万（+1193%, 数学叠加口径）* |

*组合期末数字是"每笔独立等权复利"的数学叠加，未计行情节奏、信号密度、流动性与同板块相关性影响，实际会显著低于此值。可信的核心是**单笔口径：+2.9%/月、盈亏比 2、单笔风险 ≤6%**。

注：组合口径下单笔收益（+2.91%）低于单股口径（+5.95%），属正常——组合回测计入了止损提前出场、仓位用尽跳过、以及无法长持到 20 根完整窗口的信号（止盈前被强平），更保守。

## 五、三条链路交叉验证结论

| 链路 | 平均/笔 | 胜率 | 盈亏比 | 说明 |
|---|---|---|---|---|
| A 信号库存量 | +5.6~6.7% | 68~83% | 1.7~3.1 | 无损前、独立时序 |
| B 逐股因果 | +5.95% | 82.5% | 2.96 | 无前瞻、23/23 正期望 |
| C 组合层 | +2.91% | 53.0% | 1.99 | 含止损、仓位约束、更强平 |

三条独立链路的正期望方向与量级收敛一致，说明**强多头事件策略的正期望是稳健的统计现实，而非单条链路的巧合**。

## 六、风险与局限（必须诚实列出）

1. **样本期内含 2024 偏强行情**，牛熊分布对结果有影响；未做独立于训练样本的前向验证。
2. **信号同日重叠**：同板块同涨同跌，真实组合回撤大于单笔独立模拟；需板块级去重约束后复测。
3. **A 股无裸空**：UTAD / LPSY / Shakeout 等空头/中性类型的优势在裸多体制下无法落地（方向化 +6~9% 拿不到）。
4. **组合期末数字为数学叠加**：年化/累计夸大，实盘取单笔期望与盈亏比。
5. **入出价滑点**：回测用收盘价近似，未计涨停买不进/跌停卖不出的极端流动性问题。
6. **策略衰减**：拆单/拥挤可能随时间降低部分类型边缘，需持续用评估闭环监测。

## 七、结论与执行纪律

**按"强多头事件 + 高 conf 过滤 + 结构位止损 + 仓位上限"的纪律执行，历史回测显示每笔正期望 +3~6%（1 个月持有）、胜率 53~83%、盈亏比 2~3、单笔风险可控 ≤6%——具备可盈利条件。**

实盘盈利取决于以下纪律，缺一不可：

1. **只做强多头事件**：Spring / Shakeout / ST / LPS / SC，且仅在**大盘(20日线向上) + 板块强度>60 分位 + 资金流净流入>50 分位**硬规则满足时入场（系统已内置）。
2. **conf 过滤**：优先 conf≥90（期望 +8.6%/笔 vs 全部 +5.6%）。
3. **止损必执行**：结构关键位 ± 0.5×ATR，-5% 量级；这是盈亏比 2~3 的支柱。
4. **仓位与分散**：同持上限（本测 3 只），能承受 15 笔连亏。
5. **持续校准**：依赖运行中的"评估 → 重训 → conf 接管"闭环，监测单类型边缘衰减时及时调整仓位或停用。

**待验证项（建议下一步）**：① 板块级去重约束后重跑组合回测，量化相关性回撤；② 更长历史或前向样本（离开训练窗口）验证；③ 极端流动性（涨停/跌停）敏感性。三者补齐后可建立**纳值/弃用阈值**的运行规则。
