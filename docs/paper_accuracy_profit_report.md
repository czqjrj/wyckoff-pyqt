## 六、结论与建议

**准确度**
1. 选股底座（Spring/Shakeout/ST/LPS，h20 命中 65%~85%）扎实；看空信号（UTAD/LPSY）可靠，弱市过滤有据可依。
2. JOC / PSY / SOS 不应进入多头候选，建议把它们永久移出 `LONG_EVENT_TYPES` 或在候选入池后二次拒绝。
3. VSA 区分度低（≈50%），建议维持"辅助确认"定位，不在独立扫描中单独产出候选。
4. PnF 近段方向命中 96.8% 优秀；全局档位高估 10~14pp，需缩减目标空间并继续校准。

**盈利能力**
5. 回测口径盈利显著（折中 +93.1% / 夏普 1.07 / 回撤 −13.8%），但**实盘/模拟盘样本过小**（仅 1 笔平仓），尚不能验证真实盘面绩效；建议保持默认 30 分钟自动全流程跑 4~8 周，让平仓样本 ≥30 笔再出结论。
6. 价值吸筹为明显短板，建议 `--va-min-conf` 上调或长期停用，避免重复产生止损单。
