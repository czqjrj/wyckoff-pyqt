## 结论与优化建议

**口径提醒**: "累计/复利"按每笔等权独立复利计算, 未含资金上限/信号重叠, 非真实账户收益; 判断质量请以 命中/胜率/平均单笔/盈亏比/期望 为准。

### 分层结论 (24 只 × 500 根 ≈ 2 年)
- 纪律 > 价值 > 左侧: 期望 4.87% / 3.21% / 2.52%, 盈亏比 2.35 / 2.01 / 1.32, 三策略均为正期望。
- 全部信号 ~299 条 (84 纪律 / 136 左侧 / 78 价值), 每股 ~3-6 条/500根, 对实盘 3 仓位上限信号量充足。

### 值得落地的优化
1. **左侧剔除「弹簧二次测试」(spring_retest)**: n=53 占 39%, 命中20=59% / 胜率 55% / 止损后平均 +1.72%, 明显弱于同组 "弹簧Spring"(67%/67%/+2.72%) 与 "SC后二次测试ST"(90%/91%/+3.87%)。弃用后左侧期望可由 2.52% 升至 ~3.2%+。机制已在 buypoints.py 提供 DISABLED_KINDS。
2. **纪律 conf 阈值维持 ≥100**: 100+ 段胜率 79% vs 90-99 段 66%, 实盘 MIN_CONF=100 口径正确, 无需放宽。
3. **价值吸筹的 SC 事件降权**: SC 胜率 56% 显著弱于 Spring 71% / ST 75%; 可对 SC 上调 conf 门槛或暂缓纳入。

### 注意
- 样本集中大盘蓝筹 (2 年区间 beta 偏顺风), 命中率绝对值参考有限; 落地方案后应在混合市值池 / paper_replay 全量复验。
- 基于 85/136/78 信号样本, 剔除类目属单张 backtest 子样本结论, 建议对照实盘纪律口径重复验证后再改默认。
