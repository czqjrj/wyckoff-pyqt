## 九、测量可信度 + 模型容量升级 (2026-08-28)

### P0 测量可信度

1. **P0-1 可交易口径落库**: 原"命中率"仅单 bar 方向判定, 未要求行情走完。现 `events.py` 为事件写入 `avail_idx` (确认后首根可交易 bar), VSA 记录 同步 `avail_date`; `signal_accuracy` 双口径评估 —— `ret` (历史可比) 与 `ret_c` (确认时点起算, 剔除前视)。**裂口实测**: Spring 原始 85.6% (n=369) → 确认可交易 **61.6%** (n=99); Shakeout 82.5%→57.1%; UTAD 79.4%→57.1%。报告与模型标签一律以 ret_c 优先。
2. **P0-2 符号内置换显著性**: `validation.significance_table` 新增 `"same-stock"` 置换模式 (每符号从自身收益池重采样), 避免池塘率混合; 输出带 `mode` 标记。
3. **P0-3 单标的上限加权**: 原始库中单票 (上汽集团等) 占比畸高, 池化胜率 被个别标的绑架。`load_win_rates` 现按 symbol 权重封顶 (SYMBOL_WEIGHT_CAP=50), 每符号权重 min(1, 50/count), n_eff 供显著性使用。
4. **P0-4 刻度隔离**: `validation` 全套统计按 `scale` 分别计算, 不在日线/ 30分/120分刻度间混池; 输出含各刻度独立池胜率与最强类型。

### 10.2 入口硬规则过滤 (`analysis.py:run_analysis` 尾部)

仅当 **同时满足** 三个条件才输出交易方向，否则降级为「观望 (入口过滤)」

| 条件 | 阈值 | 计算方式 |
|---|---|---|
| 大盘趋势 | `mkt_trend_20 > 0` | 日线 MA20 斜率 > 0 |
| 板块强度 | `sector_strength_pct > 0.6` | 行业强度百分位 > 60% |
| 资金流 | `fund_net_pct > 0.5` | 20 日主力净流入分位 > 50% |

- 预期组合胜率提升 **+3~5%**（强梯队+确认+置信度≥中+三重共振 → 66~68%）
- 不满足时 `trade_plan` 仅输出观望理由，`fusion.confidence="低"`，避免逆势/弱板块/资金流出时硬抗

### 10.3 止损位 = 结构关键位 ± 0.5×ATR(14) (`build_trade_plan`)

| 方向 | 结构止损 | ATR 缓冲 | 最终止损 |
|---|---|---|---|
| 多头 | Spring/SC/LPS/BU 低点 × 0.99 | `min(结构止损, 现价 - 0.5×ATR)` | 更靠近现价的保护位 |
| 空头 | UTAD/BC/LPSY 高点 | `max(结构止损, 现价 + 0.5×ATR)` | 更靠近现价的保护位 |

**关键顺序**：
1. 先按结构位（Spring 低点、派发高点等）算止损
2. **结构自洽校验**: 多头止损 ≥ 现价 或 空头止损 ≤ 现价 → 直接降级观望（买点/卖点已失效）
3. 结构有效时，再应用 **0.5×ATR(14) 缓冲**，把止损向现价方向再收紧

- 测试用例：Spring 低点 10.44，现价 10.27（已破位）→ 结构止损 10.34 ≥ 10.27 → 降级观望（不再被 ATR 掩盖）
- 预期：被扫率降低 ~10%，盈亏比 1:2 → 1:2.5
