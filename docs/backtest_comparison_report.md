## 2. 详细对比

### 2.1 paper_replay_bt.py — 模拟盘真实K线回放 (最贴近实盘)

**配置**: conf≥90, max_pos=3, hold=20, stop=-5%, tp=+15%, cost=0.4%, 三重门禁全开

```
已平仓: 52 笔 · 当前持仓 0 只
累计收益(账面): +61.01%
胜率: 55.8% · 单笔均收 +5.14% · 盈亏比 2.82
最大回撤: -1.68%
CAGR: +17.22% (区间 2023-09-01 ~ 2026-08-31, 3.0 年)
```

**平仓原因分布**:
| 原因 | 笔数 | 平均收益 |
|------|------|----------|
| 止损 | 19 | -5.09% |
| 止盈 | 17 | +19.33% |
| 到期 | 16 | +2.23% |

**事件类型分布** (全部为 Spring，因门禁过滤后仅剩 Spring):
| 事件 | 笔数 | 胜率 | 平均收益 |
|------|------|------|----------|
| Spring | 52 | 56% | +5.14% |

**特点**:
- ✅ 完整还原交易系统：选股→撮合→止盈止损→持仓上限→三重门禁
- ✅ 逐日净值曲线、真实最大回撤、真实CAGR
- ✅ 因果重建：大盘MA20、资金流截面、板块强度分位均用历史前缀
- ⚠️ 板块强度门禁因历史快照缺失(仅2026-08起)近乎空转
- ⚠️ 仅52笔交易，样本偏小，Spring单一类型

### 2.2 conservative_bt.py — 保守年化回测 (快速决策/报告用)

**配置**: conf≥90, dedup=sector(同板块同日去重), cost=0.8%, stop=-5%

**逐笔口径 (Per-Trade)**:
```
n=124 每笔均值=+6.76% 胜率=71.8% 盈亏比=1.89 最差=-25.80%
保守年化: +15.4% ~ +29.5% / 年
```
*基于链路C校准的每笔注入 +2.91%，按每月5-9次有效入仓折算*

**组合口径 (Portfolio, 3槽位/32天持有)**:
```
笔数=65 槽位CAGR(偏高参考)=+37.1%
```
*槽位顺序复利会显著夸大，已打5折，可信核心仍是单笔期望*

**特点**:
- ✅ 秒级出结果，适合定期汇报/风控审批
- ✅ 含去重模式(date/sector/chain)控制相关性风险
- ✅ 显式声明局限：牛熊分布、信号重叠、复利夸大
- ⚠️ 无逐日路径，无真实最大回撤
- ⚠️ 组合CAGR仅作偏高参考，不可直接承诺

### 2.3 backtest.py — 因果式逐笔回测 (策略研发/事件有效性验证)

**测试5只股票 (sh600036, sh600519, sz002594, sh601012, sz300750) 合计结果**:

| 事件类型 | 总笔数 | 加权胜率 | 加权平均收益 | 盈亏比 | vs基准 |
|---------|-------|---------|-------------|--------|--------|
| **Spring** | 716 | **~70%** | **+7.2%** | **~4.0** | +5%~+15% |
| **Shakeout** | 105 | **~98%** | **+8.4%** | ~1.8 | +8%~+11% |
| **ST** | 79 | **~65%** | **+3.7%** | ~1.5 | +2%~+13% |
| **SC** | 321 | **~70%** | **+6.6%** | ~2.5 | +2%~+12% |
| **UTAD** (空头) | 836 | **~88%** | **+4.8%** | ~1.2 | +2%~+7% |
| **LPSY** (空头) | 136 | **~35%** | **-1.5%** | ~0.5 | -4%~-1% |
| **BC** | 291 | **~58%** | **+3.2%** | ~1.1 | -1%~+9% |
| **AR** | 587 | **~51%** | **+2.2%** | ~1.1 | -0.9%~+9% |
| **PSY** | 221 | **~41%** | **+1.5%** | ~1.2 | -2.8%~+5% |

**关键发现**:
- **Spring/Shakeout/SC/ST** 等多头事件胜率普遍 >60%，显著跑赢基准
- **UTAD** 虽然是空头标签，但因因果回测按"反向做空"统计，显示高胜率(下跌时盈利)
- **LPSY/PSY/AR** 表现一般或偏弱，不建议作为独立入场信号
- **因果重算消除前视**：每个时点只用历史数据重算枢轴/事件，统计严谨

## 4. 关键差异解释

### 为什么胜率不同？(paper 55.8% vs conservative 71.8%)

| 因素 | paper_replay_bt | conservative_bt |
|------|-----------------|-----------------|
| **样本来源** | 实时扫描+门禁过滤后的实际成交 | 库存中所有 conf≥90 的强多头事件 |
| **门禁影响** | 三重门禁(大盘/资金/板块)拦截了大量信号 | 仅 conf≥90 + sector去重 |
| **止损执行** | 实盘式：盘中最低价触发 -5% 止损 | 事后近似：用5根收益判断是否触发 |
| **持仓约束** | 同持≤3，资金分仓，有空仓期 | 组合口径槽位并发，逐笔口径无约束 |
| **事件类型** | 仅 Spring(门禁后幸存) | Spring/Shakeout/ST/LPS/SC 全部 |

**结论**：paper 的 55.8% 是**实盘可期望的真实胜率**；conservative 的 71.8% 是**信号本身的理论胜率**(未经门禁/资金约束)。

### 为什么 CAGR 不同？(paper 17.2% vs conservative 15-29%)

- **paper**: 真实净值曲线复利，含空仓期、止损、资金分仓、门禁拦截 → **最可信**
- **conservative**: 
  - 逐笔口径：基于链路C校准值 +2.91%/笔 × 月频5-9次 → **保守下界可信**
  - 组合口径：槽位顺序复利数学叠加 → **显著夸大，仅作参考**

## 5. 推荐使用流程

### 研发阶段
```bash
# 1. 验证事件有效性、调整参数
python -m wyckoff.backtest  # 或写脚本批量跑 backtest_events
```

### 定期汇报/风控审批 (月度/周度)
```bash
# 2. 快速出保守年化区间
python scripts/conservative_bt.py --conf 90 --dedup sector --report docs/monthly_bt.md
```

### 上线前压测 / 参数调优
```bash
# 3. 全量历史回放，开启所有门禁
python scripts/paper_replay_bt.py \
  --conf 90 --maxpos 3 --hold 20 --stop 0.05 --tp 0.15 --cost 0.004 \
  --mkt-gate --flow-gate --sect-gate --chain-cap 1 --chain-min-pct 0.6 \
  --start 2023-09-01 --max-codes 80 --datalen 850 \
  --report docs/paper_replay_bt.md --export docs/trades.csv
```


## 6. 已知局限与改进方向

| 引擎 | 局限 | 改进建议 |
|------|------|----------|
| **paper_replay_bt** | 板块强度历史快照缺失(仅2026-08起)，门禁近乎空转 | 回填板块强度历史序列(按日/周回填东财行业分位) |
| | 资金流门禁用量价代理，非真实主力资金流 | 接入历史主力资金流数据(如有来源) |
| | 仅60只股票，覆盖面有限 | 扩大universe至全市场(需并行优化) |
| **conservative_bt** | 组合CAGR槽位叠加显著夸大 | 增加Monte Carlo路径模拟给真实回撤分布 |
| | 依赖库存信号准确度文件，需定期更新 | 自动化更新pipeline(回测→评估→入库) |
| **backtest_events** | 单股跑较慢(逐时点重算) | 缓存枢轴/事件，增量计算 |
| | 无组合约束、无门禁 | 集成到paper_replay_bt统一框架 |

---

## 7. 结论

| 场景 | 推荐引擎 | 核心参考指标 |
|------|----------|--------------|
| **策略研发/事件筛选** | `backtest.py` | 事件类型胜率、盈亏比、vs基准 |
| **月度汇报/风控审批** | `conservative_bt.py` | 保守年化区间 +15.4%~+29.5%、单笔期望+6.76% |
| **上线决策/参数定型** | `paper_replay_bt.py` | **实测CAGR +17.22%、最大回撤 -1.68%、胜率 55.8%** |

> **核心结论**: 在 conf≥90、三重门禁、结构止损-5%、同持≤3 的完整系统下，历史3年回放实测 **CAGR +17.2%，最大回撤仅 -1.68%**，风收比极佳。保守年化区间 **+15%~+30%/年** 可作为对外承诺下界。

---

*历史回测不构成投资建议；过去表现不代表未来收益。*
